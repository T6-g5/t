# A3-基于大模型的个性化资源生成与学习多智能体系统 - 系统架构设计

> 项目名称：基于大模型的个性化资源生成与学习多智能体系统开发
> 赛题来源：第十五届中国软件杯 A组 A3 题
> 参考文档：[00-赛题要求-A3.md](00-赛题要求-A3.md)

---

## 一、系统概述

### 1.1 项目背景

本项目旨在借助大模型技术体系，融合前沿 AI 技术，构建高等教育个性化学习资源体系，开发智能学习多智能体系统，满足学生的个性化、多模态学习需求。

### 1.2 核心目标

| 目标 | 说明 |
|------|------|
| 个性化学习 | 根据学生画像提供定制化学习内容 |
| 多智能体协同 | 通过多角色智能体协作完成复杂任务 |
| 多模态资源生成 | 支持文档、视频、思维导图等多种资源类型 |
| 防幻觉机制 | 确保生成内容的准确性和安全性 |
| 动态学习路径 | 根据学习进度实时调整学习计划 |

## 三、多智能体架构设计

### 3.1 智能体角色定义

| 智能体名称 | 角色 | 职责 |
|-----------|------|------|
| **ProfileAgent** | 画像构建智能体 | 对话式构建学生画像，提取≥6个维度特征，支持动态更新 |
| **ResourceAgent** | 资源生成智能体 | 根据学生画像和课程内容生成≥5种类型的学习资源 |
| **PathAgent** | 路径规划智能体 | 基于学生画像和知识图谱规划个性化学习路径 |
| **TutorAgent** | 智能辅导智能体 | 提供即时答疑服务，支持多模态解答形式（可选加分） |
| **AssessAgent** | 效果评估智能体 | 跟踪学习行为，多维度评估学习效果（可选加分） |

### 3.2 智能体协作流程

```
学生发起请求
    │
    ▼
┌───────────────┐
│ ProfileAgent  │ ←── 对话式交互，构建/更新学生画像
│  (画像构建)    │
└───────┬───────┘
        │ 学生画像数据
        ▼
┌───────────────┐
│  Agent调度    │ ←── 根据任务类型分配给相应智能体
│  Coordinator  │
└───────┬───────┘
        │
   ┌────┴────┬──────────────┬──────────────┐
   ▼         ▼              ▼              ▼
┌──────┐ ┌─────────┐  ┌─────────┐  ┌─────────┐
│Path  │ │Resource │  │  Tutor  │  │ Assess  │
│Agent │ │ Agent   │  │ Agent   │  │ Agent   │
│路径  │ │资源生成 │  │智能辅导 │  │效果评估 │
│规划  │         │  │(可选)    │  │(可选)   │
└──┬───┘ └───┬────┘  └────┬────┘  └────┬────┘
   │         │             │            │
   └─────────┼─────────────┼────────────┘
             ▼
      ┌──────────┐
      │  RAG     │ ←── 知识库检索，防幻觉校验
      │ 知识库   │
      └──────────┘
```

### 3.3 ProfileAgent - 学生画像构建智能体

#### 3.3.1 学生画像维度（≥6个维度）

| 维度 | 说明 | 数据来源 |
|------|------|---------|
| **知识基础** | 各学科/知识点的掌握程度 | 课程成绩、测试结果 |
| **认知风格** | 学习偏好（视觉型/听觉型/实践型等） | 对话交互、学习行为 |
| **学习目标** | 短期和长期学习目标 | 对话交互 |
| **易错点偏好** | 常犯错误类型和领域 | 测试分析、练习记录 |
| **学习节奏** | 学习速度和频率偏好 | 学习行为分析 |
| **兴趣方向** | 感兴趣的学科和领域 | 对话交互、资源访问记录 |
| **能力水平** | 综合能力评估等级 | 多维度评估模型 |

#### 3.3.2 画像构建流程

```
1. 用户发起对话
    │
    ▼
2. ProfileAgent 提取特征
    ├── 专业信息
    ├── 学习目标
    ├── 知识基础
    └── 其他维度
    │
    ▼
3. 大模型分析对话内容
    │
    ▼
4. 生成结构化画像数据
    │
    ▼
5. 存储到数据库
    │
    ▼
6. 返回画像摘要给用户
```

#### 3.3.3 对话示例

```
用户：我是计算机专业大二学生，想学习人工智能方向，目前Python基础还可以，机器学习刚入门。
Agent：已提取以下特征：
       - 专业：计算机科学
       - 年级：大二
       - 学习目标：人工智能方向
       - 知识基础：Python(中等)、机器学习(入门)
       - 兴趣方向：人工智能

用户：我平时喜欢通过实践项目来学习。
Agent：已更新认知风格为"实践型"，将为您推荐更多实操案例。
```

### 3.4 ResourceAgent - 资源生成智能体

#### 3.4.1 资源类型（≥5种）

| 资源类型 | 说明 | 生成方式 |
|---------|------|---------|
| **课程讲解文档** | 知识点详细讲解 | 大模型生成 + RAG检索 |
| **思维导图** | 知识点关联图 | 大模型生成 + 结构化输出 |
| **练习题目** | 不同难度的练习题 | 大模型生成 + 难度分级 |
| **拓展阅读材料** | 相关学术文献和文章推荐 | RAG检索 + 摘要生成 |
| **代码实操案例** | 可运行的代码示例 | 大模型生成 + 代码校验 |
| **多模态视频/动画** | 知识点讲解视频 | 文本转视频工具生成 |

#### 3.4.2 资源生成流程

```
1. 接收学生画像和学习目标
    │
    ▼
2. 分析知识短板和需求
    │
    ▼
3. 选择资源类型组合
    │
    ▼
4. 调用对应子智能体生成资源
    ├── DocGenerator → 文档
    ├── MindMapGen → 思维导图
    ├── QuestionGen → 练习题
    ├── CodeGen → 代码案例
    └── VideoGen → 视频
    │
    ▼
5. RAG防幻觉校验
    │
    ▼
6. 内容安全过滤
    │
    ▼
7. 返回生成结果
```

### 3.5 PathAgent - 路径规划智能体

#### 3.5.1 学习路径规划流程

```
1. 接收学生画像和课程信息
    │
    ▼
2. 分析知识图谱
    │
    ▼
3. 识别知识缺口
    │
    ▼
4. 生成学习路径
    ├── 步骤1：基础概念学习
    ├── 步骤2：核心知识点掌握
    ├── 步骤3：实践项目练习
    └── 步骤4：综合应用评估
    │
    ▼
5. 关联学习资源
    │
    ▼
6. 返回个性化学习路径
```

#### 3.5.2 路径规划算法

- **知识点优先级排序**：基于学生画像的知识短板和知识点依赖关系
- **学习节奏匹配**：根据学生的学习速度调整路径长度
- **动态调整机制**：根据学习效果实时调整路径

## 八、关键技术实现

### 8.1 RAG防幻觉机制

#### 8.1.1 实现策略

```
1. 文档预处理
    ├── 分块
    ├── 嵌入向量
    └── 存储到向量数据库

2. 查询时检索
    ├── 用户问题向量化
    ├── 相似度检索（top-k）
    └── 返回相关文档片段

3. 生成时校验
    ├── 将检索结果作为上下文
    ├── 大模型生成回答
    └── 引用来源标注

4. 后处理校验
    ├── 事实性检查
    ├── 敏感内容过滤
    └── 格式规范校验
```

#### 8.1.2 防幻觉技术点

| 技术 | 说明 |
|------|------|
| **引用标注** | 生成内容标注来源文档 |
| **事实核查** | 使用大模型验证关键事实 |
| **内容安全** | 使用安全分类模型过滤敏感内容 |
| **置信度评估** | 评估生成内容的置信度 |

### 8.2 多智能体协同机制

#### 8.2.1 智能体通信协议

```python
class AgentMessage:
    sender: str           # 发送者智能体名称
    receiver: str         # 接收者智能体名称
    message_type: str     # 消息类型（request/response/notify）
    content: dict         # 消息内容
    timestamp: datetime   # 时间戳
    correlation_id: str   # 关联ID（用于追踪请求链路）
```

#### 8.2.2 智能体调度流程

```
1. 接收用户请求
    │
    ▼
2. 解析请求类型
    │
    ▼
3. 选择目标智能体
    │
    ▼
4. 构建消息并发送
    │
    ▼
5. 智能体处理请求
    │
    ▼
6. 返回响应
    │
    ▼
7. 路由到用户
```

## 十二、风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|---------|
| 大模型API调用失败 | 核心功能不可用 | 配置多模型切换，实现降级策略 |

| 前端性能问题 | 页面加载慢 | 代码分割、懒加载、缓存优化 |
